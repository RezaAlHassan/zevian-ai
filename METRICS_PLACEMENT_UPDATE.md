# Submit Report Page - Organizational Metrics Placement Update

## Changes Made

### ✅ Moved Organizational Metrics Cards
**From:** Top of the page (after welcome section)  
**To:** Under "Report Details" heading (contextually relevant placement)

### ✅ Added Clarity Subtext Under Report Details
The subtext now appears right where employees need it - when they're about to write their report:

> "Focus on clarity and results. The analysis looks beyond keywords to understand the actual value delivered."

### ✅ Improved Layout Structure

**New Flow:**
1. **Welcome Section** - Simple introduction
2. **Employee Selection** (if manager view)
3. **Project Selection**
4. **Goals Selection**
5. **Report Details** ← Metrics cards are here now
   - Heading: "Report Details"
   - Subtext: Clarity guidance
   - **Evaluation Criteria Cards** (if org has selected metrics)
     - Shows 70/30 weighting explanation
     - Displays metric cards in responsive grid
   - Rich Text Editor

## Why This Is Better

### 🎯 **Contextual Relevance**
- Metrics appear exactly when employees need them - right before writing
- The guidance is at the point of action, not buried at the top

### 📱 **Better UX Flow**
- Top section stays clean and simple
- Evaluation criteria appear after goal selection (when they become relevant)
- Employees see what they'll be evaluated on immediately before writing

### 💡 **Clearer Messaging**
- "Focus on clarity..." message is now positioned where it matters most
- Removed duplication from top section
- Metrics cards are more compact (smaller padding, tighter spacing)

## Visual Changes

**Metrics Cards:**
- Background: `bg-surface` (subtle, not pure white)
- Padding: Reduced from `p-4` to `p-3` (more compact)
- Font sizes: Smaller and tighter for better density
- Heading: Changed from `h2` to `h3` (appropriate hierarchy)

**Result:** A cleaner, more focused submit report experience! ✨
